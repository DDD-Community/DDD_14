## 스텝 3. 이름 규칙을 사용자의 뜻에 맞게 고친다

**요청 (사용자)**: 구현 계층의 이름은 응용 계층과 같을 필요가 없다. 수정은 `Update`일 때도 `Modify`일 때도 있다. 1.13은 인프라 계층의 메서드 이름을 구현 계층의 이름에 쓰지 말라는 뜻이었다.

**결정 (사용자)**:
- 이름을 같게 짓는 범위에 구현 계층을 넣지 않는다.
- 수정의 입력 DTO는 상황에 맞춰 `Update`나 `Modify`를 쓴다.
- 인프라의 이름을 막는 곳은 구현 계층의 메서드 이름이다.

**한 일 (AI)**:
1. ADR-0006의 1.9, 1.13, 1.14를 고치고 1.16과 1.17을 더했다. 1.13은 "인프라 계층 밖의 모든 이름"으로, 1.14는 수정을 `Modify`로만 잘못 적었다.

**남은 일**:
