# Code Review Rule

자동 리뷰(`client-review-changes` 스킬)와 사람 리뷰가 함께 쓰는 체크리스트다. lint·타입·테스트가 잡는 것은 다시 보지 않는다.

## 체크리스트

- [ ] 동작이 관련 `specs/`와 일치한다. 동작이 바뀌었다면 spec도 갱신했다
- [ ] 테스트가 요구사항을 검증한다. 테스트를 지우거나, skip하거나, 기대값을 구현에 맞춰 약하게 바꾸지 않았다
- [ ] 서버 데이터를 zustand에 복사하지 않았다 (서버 상태는 TanStack Query)
- [ ] 책임이 맞는 레이어·feature에 있다 (lint가 못 잡는 설계 문제)
- [ ] `shared/`에 이미 있는 것을 다시 만들지 않았다
- [ ] 로딩·에러·빈 상태를 처리했다
- [ ] 접근성: 버튼·링크·폼 라벨, 키보드 조작
- [ ] 디버그 코드, 쓰지 않는 코드, 불필요한 의존성이 남아 있지 않다

## 보고 형식

- 지적은 `[필수]`와 `[권장]`으로 나누고 `파일:줄`을 붙인다.
- 문제가 없으면 "지적 없음"이라고 쓴다.
- 고치지 않은 지적은 이유를 한 줄로 남긴다.
